# EV3-Soccer-Ball-Transport-and-Launch-System

In this project focused on programming an EV3 robot to transport a soccer ball through an obstacle course and successfully launch it at the end. The robot was designed to securely carry the ball while navigating obstacles without losing control or accuracy. The program controlled motor speed and timing to maintain stability during movement, while sensors were used to detect key checkpoints in the course. After completing the course, the robot executed a launch mechanism to throw the soccer ball accurately. This project emphasized integration of mechanical design and software logic, as both had to work seamlessly for the task to succeed. The final code reliably completed the course and launched the ball as intended.
